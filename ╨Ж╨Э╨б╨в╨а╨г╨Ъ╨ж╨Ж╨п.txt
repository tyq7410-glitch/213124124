DEAD VISUALS - дуже проста інструкція

Тобі потрібен Minecraft 1.21.4 з Fabric (і Fabric API).

КРОК 1. Розпакуй цей zip (правою кнопкою -> "Розпакувати все").
КРОК 2. Зайди на github.com, зареєструйся, натисни "New repository", назви як хочеш, натисни Create.
КРОК 3. У репозиторії натисни "uploading an existing file" і перетягни ВСЕ з розпакованої папки
        (разом з папкою .github, на Windows вона видима).
        Внизу натисни "Commit changes".
КРОК 4. Угорі відкрий вкладку "Actions" і зачекай 3 хвилини, поки з'явиться зелена галочка.
КРОК 5. Відкрий збірку, внизу в "Artifacts" натисни dead-visuals-mod (скачається zip).
КРОК 6. Розпакуй його. Файл deadvisuals-1.0.0.jar (БЕЗ слова sources) кинь у папку mods.
        Fabric API теж має лежати в mods.

Якщо замість зеленої галочки червоний хрестик: відкрий його, скопіюй текст помилки й відправ мені.

КЛАВІШІ В ГРІ
Right Shift - меню. ЛКМ вмикає, ПКМ відкриває налаштування.
V - емоції. G - мітка. H - прибрати мітки.

ЯК ЗМІНИТИ НЕБО
Меню -> вкладка "world" -> "sky & weather" (ПКМ) -> Time / Weather / Sky color.

ДЛЯ FPS
Вкладка extras -> performance. Для сильнішого приросту додатково постав Sodium і Lithium.
