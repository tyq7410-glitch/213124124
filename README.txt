DEAD VISUALS - BUILD

GitHub:
1. Upload this project to a GitHub repository.
2. Open Actions -> Build DeadVisuals.
3. Run workflow.
4. Open the completed run -> Artifacts -> DeadVisuals.
5. Inside the downloaded ZIP is the .jar for Minecraft 1.21.4.

Local:
Install Java 21 and Gradle 8.x, then run build.bat.
The mod JAR will be in build/libs/.
